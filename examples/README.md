# Physiotherapy AI Model

An open-source physiotherapy AI system that uses computer vision to track body movements, calculate joint angles, and provide real-time feedback based on medical standards.

## Features
- Pose detection (MediaPipe/OpenPose backbone)
- Angle calculation utilities
- Clinical rules engine (squat, gait, upper limb)
- Real-time feedback (text + voice)
- API endpoints for integration
- Session reports (PDF summaries)
